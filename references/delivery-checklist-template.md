# 交付清单模板

开始生成前按用户要求建立清单；生成后逐项核对。

## 一、清单

| 编号 | 交付内容 | 版面 | 状态 |
| --- | --- | --- | --- |
| P01 | 主体多角度视图 | 主体板 | 待完成 |
| P02 | 头部细节 | 主体板 / 细节板 | 待完成 |
| P03 | 特殊器官 | 细节板 | 待完成 |
| P04 | 模块拆解 | 主体板 | 待完成 |
| P05 | 骨骼与关节 | 主体板 | 待完成 |
| P06 | 材质与配色 | 主体板 | 待完成 |
| U01 | UV 示意 | 主体板 | 待完成 |
| A01 | 待机 / 休眠 | 动画板 | 待完成 |
| A02 | 移动 / 游动 | 动画板 | 待完成 |
| A03 | 攻击 / 特殊能力 | 动画板 | 待完成 |

## 二、状态定义

| 状态 | 含义 |
| --- | --- |
| 待完成 | 尚未生成 |
| 已完成 | 已完整展示并通过检查 |
| 待修正 | 已生成但存在错误或不足 |
| 不适用 | 该生物不存在此结构或动作 |

## 三、完成判定

只有同时满足以下条件才能标记“已完成”：

- 画面中能找到对应内容。
- 主体完整、未被裁切。
- 结构、编号与术语正确。
- 与设计基准一致。
- 文字可读且无错误。

## 四、最终核对

- 是否缺少用户要求的图片。
- 是否缺少局部结构。
- 是否有未展示的动作。
- 是否有不完整的关键帧。
- 是否有被裁切或缩得过小的主体。
- 是否有未完成的工程内容。
- 是否存在未完成却标记完成的条目。
