# Blockbench 工程实测踩坑清单

以下约束来自对 Blockbench 4.x/5.x 工程文件与第三方读取器的实际验证，生成或修改 `.bbmodel` 时逐条对照。

## 1. UV 与贴图

- **`box_uv` 必须为 `false`**：工程级 `meta.box_uv` 和**每个 cube 的 `box_uv`** 都要关掉。任一为 `true`，读取器会忽略逐面 `uv`，改按 `uv_offset` 重算盒式 UV，整片零件采到贴图左上角。
- **逐面 UV 方向**：`v` 轴从上往下；约定从外侧看正立、不镜像。正面朝向 `-Z`（north）。
- **UV 矩形要留 1–2 像素 gutter**：部分预览器按闭区间采样，相邻面共边会渗色；脚本已自动留 2 像素并做边缘 clamp 扩边。
- **`bedrock` 实体格式是单贴图**：第二张贴图在 GUI 里会被忽略并回落成 `texture 0`。多部件必须合并进同一张图集。

## 2. 文件格式版本

- `meta.format_version` 写 `"4.5"` 最稳。用 Blockbench 5.x 打开并重新保存后会变成 `"5.0"`：
  - 4.5：组的 `origin`/`rotation` 内联在 `outliner` 节点上；
  - 5.0：组变换移到顶层 `groups` 表，`outliner` 只保留 uuid 引用。
- 同时写内联节点与顶层 `groups` 表可兼容两类读取器；Blockbench 按 uuid 合并，不会重复。

## 3. 骨骼与动画

- **动画只键组，不键方块**：方块级 rotation/scale 绕模型原点执行，会把零件甩出模型。需要动的部件先归入带 `origin` 的组。
- **静息角放在 cube 上**：动画关键帧会整体替换组旋转；把初始俯仰/张角写在组上，第一个关键帧就会把它抹掉。组保持 0 旋转，关键帧表达“在静息姿态上再弯多少”的增量。
- **链式关节**：每段绕上一关节旋转，段与段用元素 `rotation` + `origin` 表达姿态，组按父链串接。
- 关节位置对齐 0.5 网格；方块尺寸保持整数单位（UV 矩形由尺寸决定）。

## 4. 几何与渲染

- **轴对齐方块堆不出球体**：多层等高方块会读成屋檐/台阶。曲面用多面体收口，或用一圈板围成多边形。
- **尖刺在两个横轴同时收口**，只收一个轴顶端会留大平面，读成“板”。
- **共面重叠会 z-fighting**：绕同轴逐级旋转的相邻件、圈/管/拱的搭接面都要错开厚度（如逐片 ±0.03）或改写宽度档位。
- **环/箍要跨在杆端面上**：环内径等于杆宽才有面接触，否则只沿一条线接触，被判为未连接。
- **眼睛要凸出眼窝前表面约 0.2 单位**，整颗埋进实心眼窝会渲染成全黑。
- **相邻板的同一朝向侧面不要同宽**：转角处共面并重叠，只有世界坐标扫描能抓到。

## 5. 镜像与命名

- 镜像件与原件**放在同一个组**，名字按 `_l`/`_r` 成对；侧标放在序号**后面**（`knee_spike0_l`，不是 `knee_spike_l0`），否则镜像配对失败。
- 骨骼/组统一英文 `snake_case`，展示图标签用中文。
- cube 名称与 group 名称都必须唯一；脚本会拒绝重复名。

## 6. 交付前检查

1. `node scripts/validate_bbmodel.mjs <model.bbmodel>` 通过（无孤立件、无重复 uuid、无 UV 越界/重叠、动画骨骼全部可解析）。
2. 贴图 PNG 为有效 RGBA，尺寸与 `resolution` 一致。
3. 在 Blockbench 中实际打开一次，切换正/侧/背视图确认朝向与镜像正确。
4. 播放每个动画，确认关节链弯曲方向正确、无零件飞出、无穿地。
