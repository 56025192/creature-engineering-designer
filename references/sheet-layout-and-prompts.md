# 动态版式规划与母提示词

本文件不再规定固定工程板数量或固定行列模板。版式由生物结构、内容容量与用户要求决定。

## 一、版式决策

先列出需要展示的内容，再判断单张能否清楚承载。

| 情况 | 建议版式 |
| --- | --- |
| 内容 ≤ 6 项，主体结构简单 | 单张纵向工程板（`3:4` 或 `4:5`） |
| 内容 7–10 项，含拆解与骨骼 | 单张纵向工程板，或横向 `16:9` 宽幅 |
| 含多组动作、关键帧、复杂触手/翼展 | 主体板 + 独立动画板 |
| 含大量局部特写或特殊器官 | 主体板 + 细节板 |
| 多形态/变形生物 | 每个形态一张，另加一张形态对照 |

方向选择：

- **纵向 `3:4` / `4:5`**：主体高瘦、蛇形、人形、悬浮体。
- **横向 `16:9` / `21:9`**：翼展宽大、四足、多肢横向展开、动作序列。
- **方形 `1:1`**：单形态细节板、材质板、单动作分解。

分板目的不是增加图片，而是确保每项内容完整可见。

## 二、分板触发条件

出现以下任一情况必须扩大区域或分板：

- 主体高度或宽度被压缩到看不清结构。
- 局部细节小于可辨识尺度。
- 动作姿态被裁切或模型过小。
- 标签需要小于可读字号。
- 模块之间开始重叠遮挡。
- 用户要求的项目没有空间展示。

## 三、常见版式骨架（示例，非强制）

### 1. 纵向工程板

- 顶部：名称 / 类别 / 版本。
- 上部：多角度视图。
- 中部：局部细节 + 模块拆解。
- 下部：材质、骨骼、动作、碰撞。
- 右侧或底部：档案与图例。

### 2. 横向宽幅

- 左侧：主体大图 + 多角度。
- 中部：拆解与骨骼。
- 右侧：动作序列与档案。

### 3. 细节板

- 每格一个部位，编号 + 短标签。
- 一格只表达一个结构，不塞多个器官。

### 4. 动画板

- 每行动作数量由画幅决定，不设固定上限。
- 每个动作带唯一编号（`A01`…）。
- 复杂动作独占更大的格子。

## 四、容量检查

出图前逐项判断：

- 主体是否足够大。
- 每个细节是否清晰。
- 每个动作是否完整。
- 文字是否易读。
- 结构关系是否明确。
- 是否有遮挡或裁切。
- 用户要求的项目是否全部有位置。

任何一项为否，先调整版式，不要缩小内容硬塞。

## 五、母提示词模板

```text
为【生物名称】（【类别/拓扑】）制作【单张/多张】Minecraft / Blockbench 体素风工程展示图。

画幅与版式：
【纵向 3:4 / 横向 16:9 / 方形 1:1】；
【版式说明：主体视图在左，拆解在中，动作与档案在右】；
分区用低饱和暗金细线，深蓝黑工程底板，简体中文短标题。

必须包含：
1. 【项目 P01】……
2. 【项目 P02】……
3. 【动作 A01】……

视觉风格：
全部几何由立方体、长方体与阶梯模块构成；
16×16 或 32×32 像素贴图质感，每材质 3–4 阶明暗；
硬边像素轮廓，正交 / 等距视角，硬边接触阴影。
禁止平滑曲面、写实皮肤、镜面反射、景深与体积光。

模块分离：
相邻模块使用可区分底色，并保留 1–2 像素深色接缝或描边；
关节处留可见缝隙；搭接件错开一档；
禁止头身不分、触手糊团、翅膀与躯干同色相连。

跨图一致：
所有图片使用同一设计基准：相同轮廓、比例、材质、配色、模块数量与特殊器官。

文字：
只使用必要短标签（2–6 字）与编号；
术语全图统一；比例、尺寸、编号不得矛盾；
禁止乱码、错字、镜像字、重复标签与未替换占位符。
若文字生成不稳定，画面只放 01/02/03，图例移至底部或档案栏。

严格约束：
只出现【生物名称】这一种生物；
严格遵循其自身解剖，不得套用其他物种的角、鬃、鳞甲或蹄足；
不得把工程图表述为可导入的三维模型。
```

## 六、文字降级顺序

图像模型对中文长文本不稳定时，按以下顺序降级：

1. 全中文短标签。
2. 中文短标签 + 英文小字。
3. 纯编号 + 底部图例。
4. 无文字模型图 + 独立说明文档。

任何情况下不得用错误文字填充画面。

## 七、版式否决项

- 为凑固定栏位虚构不存在的器官。
- 主体被压缩到无法辨认仍强行单板。
- 动作被裁切、缩小或合并。
- 文字覆盖模型或小于可读字号。
- 拆解件无连接关系地漂浮。
- 不同图片出现不同版本的主体。
