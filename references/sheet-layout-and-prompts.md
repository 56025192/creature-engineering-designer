# 工程设定图版式与提示词规范

## 一、画布选择与防过载策略

| 模式/场景 | 推荐比例 | 版式结构 | 适用说明 |
| --- | --- | --- | --- |
| 模式 B 默认工程板 | 3:4 或 4:5（竖向，1800×2400 起） | 左侧 78%–80% 七排工程区 + 右侧 20%–22% 贯通档案栏 | 垂直分区清晰，最不易挤压文字或导致多视角变形 |
| 模式 A 视觉设定板 | 16:9 或 4:5 | 主区五视图 + 3–5 局部细节 + 色板材质；右侧/底部档案栏 | 信息密度适中，适合外观定型阶段 |
| 超复杂生物 / 用户指定宽幅 | 16:9 / 21:9 或双图分板 | 分板 1：五视图 + 局部细节 + 爆炸拆解 + 档案；分板 2：骨骼关节 + 材质UV + 动作 + 关键帧碰撞 | 当生物拥有多形态、大量触手或机甲零件时，优先拆成双板以保证清晰度 |

## 二、视觉语言规范

- **背景**：深蓝黑、深青黑或与物种相契合的暗色工程展示底板（可带极细工程网格或低对比暗纹）。
- **分区边框**：低饱和暗金或冷铜工程细线，严禁粗重边框喧宾夺主。
- **造型语言**：Minecraft / Blockbench 体素风。全部由立方体、长方体与阶梯模块构成；`16×16` 或 `32×32` 像素贴图质感；硬边像素轮廓；禁止平滑曲面、写实毛发与照片级材质。
- **标题与标注**：清晰简体中文短标题，避免大段密集小字。
- **风格借鉴红线**：若用户提供参考图，仅沿用版式分区、底板色调、线框风格和渲染精度；绝对不借用参考生物的头型、角、鬃毛、鳞甲、蹄足或武器。

## 三、左侧七排工程内容（对应 A–K 区）

1. **第 1 排（15%）— A：整体五视图**
   `正视图`、`左视图`、`背视图`、`右视图`、`45°立体视图` 五等分等高排列；统一地面线、统一站姿、不裁切翼/尾/触角。
2. **第 2 排（12%）— B：身体局部细节**
   5 张高清特写，按物种现选部位（人形选头面/甲胄/手部/腿靴/武器；克苏鲁选主眼/口器/触手吸盘/异形囊腺/能量核；机械选头部感应器/动力核心/液压关节/外甲/推进器）。
3. **第 3 排（15%）— C：模型爆炸拆解**
   保留空间组装顺序、插接轴向与左右对称关系；零件不无故悬浮、不重复、不漏关键器官。
4. **第 4 排（13%）— G/H：材质、色板与 UV 示意**
   标注主色/辅色/高光/金属/能量/透明材质及编号；展示 `128×128`（或 `256×256`）贴图分布与部位映射示意（明确标注“UV 概念参考”）。
5. **第 5 排（15%）— D/E：骨骼层级与关节轴向**
   左侧骨架叠加模型，中部简化骨链树，右侧关键关节旋转中心、XYZ 旋转轴及角度范围。
6. **第 6 排（19%）— I：七种动作姿态**
   默认 `4 + 3` 两行或七等分：`待机 / 行走 / 奔跑 / 跳跃 / 攻击 / 受伤 / 死亡`，按物种替换为 `游动 / 飞行 / 潜行 / 触手摆动 / 施法 / 变形`。
7. **第 7 排（11%）— F/J/K：关键帧、尺寸与碰撞**
   关键帧起/中/末态轨迹（含参考比例尺度）+ 独立亮青/亮蓝线框碰撞箱、头部/躯干/肢体受击区、接地点与攻击范围。

## 四、右侧竖向生物档案（L 区）

窄长贯通右侧全高，字段按需填写，未知精确数值标注“参考”或省略，不强行编造体重/尺寸：

- 生物名称与英文代号
- 所属类别与拓扑原型
- 体型 / 参考比例（总高、总长、头身比）
- 世界观 / 栖息环境
- 外观与材质特征
- 核心能力与攻击/防御方式
- 行为习性
- 工程规格备注（贴图规格建议、主要骨链数、动作状态列表、工程图性质：视觉设定 / 构造示意）

```text
深蓝黑暗色工程底板，低饱和暗金细线清晰分区，简体中文工程小标题。

左侧七层依次排布：

4. 128×128 像素贴图色板、材质索引与 UV 部位映射示意；
5. 真实可动部件的骨骼层级图、枢轴点、旋转轴向与关节活动范围；

严格约束：
- 仅出现【生物名称】这一种生物，所有视图、特写、拆解和动作必须为同一套模型零件与配色；
- 严格遵循【生物名称】自身的解剖结构，绝不套用其他物种特征（禁止强行添加无关的麒麟角、龙首、狮鬃或蹄足）；
- 骨骼必须对应真实可动部件，碰撞线框必须与生物实体清晰分离，文字排布留白充足不遮挡模型。
```

## 六、质量否决清单

出现以下任一情况必须重做或修正后再交付：
- 不同视角长出不一致的角、翼、尾、武器或肢体数量。
- 局部特写与全身模型配色或零件结构冲突。
- 爆炸拆解零件漂浮无连接逻辑，或左右对称件数量不匹配。
- 骨骼画在表面装饰上，或未绑定真实活动部件。
- 碰撞线框与模型实体混淆。
- 将概念设定图或 UV / 骨骼示意图宣称为可导入的三维模型文件。
